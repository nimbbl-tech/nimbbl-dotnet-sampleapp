# Web Framework Examples

This directory contains example implementations for integrating Nimbbl V3 API with different ASP.NET frameworks.

## ASP.NET Core Example

`ASPNETCoreExample.cs` demonstrates how to:
1. Generate merchant token
2. Create an order
3. Launch checkout in a service class

## ASP.NET MVC Example

`ASPNETMVCExample.cs` demonstrates how to:
1. Generate merchant token
2. Create an order in a controller action
3. Handle payment callbacks

## Usage

These examples show the basic integration pattern. For a complete working sample, see the main `nimbbl-dotnet-sampleapp` project.
